# Install the iClexi Profile

Repository target:

```text
iClexi/iClexi
```

## Files

Copy:

```text
README.md
.github/workflows/snake.yml
```

into the public `iClexi/iClexi` repository.

## Contribution animation

After the files are committed:

1. Open the **Actions** tab.
2. Select **Generate Contribution Trace**.
3. Run the workflow manually once.
4. The workflow creates/updates the `output` branch.
5. The README automatically loads the light/dark contribution SVG from that branch.

The workflow also runs daily.
